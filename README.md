#### 🔐 SecureScan – Fraud Detection System

* ML pipeline for detecting **fraudulent mobile financial transactions**
* Built **Streamlit dashboard** to visualize risk scores, probabilities & insights
* Implemented **feature engineering** & **model interpretability tools (SHAP)**
* [📂 View Code](https://github.com/Anutri03/Fraud_detection_ml)

#### ⚖️ LawGPT – Legal Q&A Chatbot

* Developed using **LangChain**, **FAISS**, and **OpenAI embeddings**
* Enables retrieval-based legal Q&A on large text databases
* Built for the **Dhaal.io MVP project** at Sahind Technologies

* Detects forgeries in **videos and images** using **DFDC** & **FaceForensics++ datasets**
* Focused on improving **spatial-temporal analysis** and **forgery localization**

#### 🚗 Used Car Price Prediction

* Regression models (Linear, Random Forest, Decision Tree) predicting used car prices

#### 🛒 Product Cluster Analysis

#### 👕 Clothing GAN – Fashion Image Generation

#### 🌐 URL Phishing Detection
